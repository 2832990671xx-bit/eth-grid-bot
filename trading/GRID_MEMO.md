# 网格交易备忘录

> 2026-05-29 整理，来源：OKX模拟盘实践 + MoneyZG / Coin Bureau / VirtualBacon 视频学习

---

## 🧠 核心理念

- **网格不是印钞机**，是震荡市里赚波动的工具
- **长期稳健 > 短期暴利** — 小亏不亏、小赚常赚
- **网格只在横盘震荡时有效**，单边行情要休息

---

## 📈 市场判断（开网前必看）

### 适合开网 → 横盘/震荡
- 价格在区间内来回走，不创新高、不创新低
- 波动幅度3-6%
- 特征：K线上下影线多、无明显趋势

### 不适合开网 → 单边行情
- 连续3天以上同向（一直跌/一直涨），**不开网**
- 下跌趋势里开网格 = 一路买到底，浮亏越来越大
- 上涨趋势里开网格 = 频繁卖飞，吃不到大行情

### 最佳时机：**横盘区下沿**
- 等价格跌到横盘底部再开，安全边际高
- 参考Coin Bureau建议：**等市场底部确认后开网**

---

## ⚙️ 参数设定

### 区间选择
| 情况 | 建议 |
|------|------|
| 震荡市 | 当前价±10-15% |
| 宽幅震荡 | 当前价±15-25% |
| 不确定趋势 | 宁宽勿窄（避免被突破出界） |

### 格数选择
| 格数 | 特点 |
|------|------|
| 10-15格 | 格距大、单笔利润高、交易频率低 |
| 20-25格 | ✅ **推荐** — 平衡利润和频率 |
| 30+格 | 格距小、频繁交易但手续费吃利润 |

> ⚠️ Coin Bureau 验证：80格vs25格的回测，80格反而赚更少（手续费吃掉利润）

### 等比 vs 算术
- 选 **等比（几何）** — 每格固定百分比
- 算术只适合价差固定的小范围

---

## 💰 风险管理

### 止损
- **必须设！** 价格跌破区间下沿5%时清仓止损
- 网格没有自动退出机制，不断买跌会死很惨

### 资金
- 模拟盘测试满意再上真金
- 实盘也不要用全部资金，留一半机动
- 网格适合分配部分仓位，不是全仓策略

### 杠杆
- **永远不要上杠杆做网格** — 合约网格容易爆仓
- 只做现货网格

---

## 📋 操作流程

```
1. 看市场趋势 → 横盘？→ 继续
                 → 单边？→ 等待
2. 选区间 → 支撑位~阻力位
3. 设格数 → 20-25格
4. 等比模式
5. 设止损 → 跌破下沿5%自动退出
6. 投入资金
7. 定期查看 → 市场结构变了就停
```

---

## 🚨 退出信号
- 价格突破区间上沿且继续拉升（踏空风险）
- 价格跌破止损线（最大亏损已到）
- 市场从震荡变单边
- 已积累足够利润，想锁定收益

---

## 📊 自我提醒

| 不要做 | 应该做 |
|--------|--------|
| 不判断趋势就开网 | 先看市场结构再决定 |
| 格数设太多以为更稳 | 20-25格就够了 |
| 网格盈利了加杠杆 | 保持现货，不加杠杆 |
| 价格跌了硬扛不设止损 | 止损就是保命 |
| 看到单边行情还抱着网格不放 | 有单边信号就停 |

---

> **最后记得：** 网格交易赚的是时间的钱，不是运气的钱。耐心等机会，参数调好就别频繁改，让时间去跑。
